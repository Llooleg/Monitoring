ADS-B. Use the community aggregators rather than commercial APIs. Most speak the same ADSBExchange-v2-style schema, so you can swap between them. adsb.fi allows 1 request/second on public endpoints for personal, non-commercial use with attribution, and airplanes.live is also 1 request/second and non-commercial. One comparison also lists a 500 requests/day cap on airplanes.live’s free tier, which matters if you poll. adsb.lol has load-based dynamic rate limits, ODbL-licensed data, and free annual historical dumps. That last part is useful because you need history to build baselines. Its repo says there are no rate limits currently, but it may add limits and require a key you get by feeding a receiver. Also, ADSB One appears to have been archived in April 2026 after merging into airplanes.live, so don’t build on it. OpenSky is the other big open network, but I couldn’t verify its current auth and quota terms, so read its docs before committing.

BGP. RIPE RIS Live is a real-time BGP streaming API with server-side filtering by prefix or AS, so subscribe to specific networks instead of drinking the firehose. RIPEstat has a REST API with rate limits that are generous for normal use, which suits periodic polling. BGPStream can read both RIS Live and Route Views’ live stream, so one library covers both. For pre-digested anomalies, Cloudflare Radar’s free API exposes hijacks, leaks, and more under its BGP endpoints. One caveat: Radar’s own about pages disagree on the license. The German page says API data is CC BY-NC 4.0, while the French page says CC BY 4.0. For a personal project it doesn’t matter, but check before you publish anything.

SEC filings. EDGAR is the easy one. It’s free and keyless, with JSON endpoints on data.sec.gov plus daily and quarterly index files for bulk work. The rules are a 10 requests/second ceiling and a declared User-Agent with your contact info, and automated crawling outside the policy gets throttled. In practice that means bursty or anonymous clients get a wall of 403s, so poll the index files and cache everything. Also, EDGAR only accepts filings on business days from 6am to 10pm ET, so an anomaly at 3am Sunday is a bug in your pipeline, not a signal. Put that in the baseline.
